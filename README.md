# 🐍 CodeAlpha Python Programming Internship

Welcome to my **CodeAlpha Python Programming Internship Projects** repository!

This repository contains two Python projects developed as part of my internship at CodeAlpha to improve my Python programming, problem-solving, and practical development skills.

## 📌 Projects

### 1. Stock Portfolio Tracker

A Python application that calculates stock investments using predefined Indian stock prices.

**Features:**
- Display predefined Indian stocks.
- Add stocks and quantities.
- Calculate individual stock investments.
- Calculate total portfolio investment.
- Combine duplicate stock entries.
- Save portfolio details in CSV format.
- Load previously saved portfolio data.
- Menu-driven interface.

**Technologies Used:**
- Python 3
- CSV Module
- OS Module

**Currency:** Indian Rupees (INR)

**Run the project:**
```bash
cd CodeAlpha_StockPortfolioTracker
python main.py
```

### 2. Basic Chatbot

A simple rule-based chatbot developed using Python. It interacts with users through predefined questions and responses.

**Features:**
- Greeting responses.
- Responds to predefined questions.
- Recognizes user messages.
- Handles unknown inputs.
- Interactive conversation.
- Exit functionality.

**Technologies Used:**
- Python 3
- Functions
- Conditional Statements
- While Loops
- String Handling

**Run the project:**
```bash
cd CodeAlpha_BasicChatbot
python chatbot.py
```
